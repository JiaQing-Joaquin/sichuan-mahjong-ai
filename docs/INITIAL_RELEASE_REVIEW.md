## 仍需注意

- 流局赔偿是简化实现；番型、杠分、封顶及抢杠等细则须按目标平台的真实牌谱逐项对账。
- 现有测试覆盖大量规则情形，但缺少目标平台的牌谱回放和跨规则配置的结算对账集。
- 历史模型评测缺少逐局得分、置信区间与完整实验元数据。PPO 使用终局回报减价值基线，未实现 GAE、KL 早停或动态对手池更新。
- 尚无服务端推理接口、房间管理或多局积分；`docs/M3_SERVING.md` 仍是方案。

## 下一步优先级

1. **规则正确性**：建立真实牌谱回放与计分对账集，固化玩法配置和零和校验。
2. **评测可信度**：保存每局四座身份、得分、种子、检查点与代码版本；做多种子评测和置信区间。
3. **训练质量**：完善可复现检查点元数据，扩大样本与对手多样性，再比较 GAE、熵系数和裁剪设置。
4. **产品集成**：在规则口径稳定后增加独立推理接口、异常处理与部署监控。
